# Mechanic Workshop App

Aplicación móvil para taller mecánico enfocada en control de inventario, servicios, rutas y historial.

## Descripción

Esta app permite:

- registrar inventario y catálogo de piezas
- definir servicios personalizados con precio
- gestionar rutas de trabajo
- llevar historial por ruta
- controlar salidas de inventario al guardar una cotización o registro
- usar la app desde celular con una interfaz simple y rápida

## Stack

- Next.js
- React
- TypeScript
- Tailwind CSS
- Local storage para persistencia local

## Ejecutar localmente

```bash
npm install
npm run dev
```

Luego abre:

http://localhost:3000

## Producción

La app está preparada para publicarse en hosting como Vercel y para uso desde celular.
